# ROS2 端上下货动作实现方案

日期：2026-05-29

## 1. 说明

本地仓库没有 ROS2 车辆端代码。本文是提供给 ROS2 团队实现的接口和行为要求，不在本地代码库内落地 ROS2 节点。

ROS2 端只需要面向 Sidecar 提供标准 Action 能力，不需要理解 jvs-opentcs 的订单、库存、调度算法。订单、库存、车辆载货和异常处理由本地 openTCS/core 负责。

## 2. ROS2 端职责

ROS2 端负责：

- 接收 Sidecar 发起的装货 Action。
- 接收 Sidecar 发起的卸货 Action。
- 控制车辆侧硬件、PLC、机械臂、输送线或传感器完成实际动作。
- 返回实际完成物料清单。
- 返回车辆当前载货清单。
- 支持取消、超时、失败、部分成功。
- 可选发布车辆载具状态 topic，用于诊断和展示。

ROS2 端不负责：

- 创建订单。
- 拆分订单。
- 判断车辆是否应该接单。
- 扣减或增加仓库库存。
- 修改 jvs-opentcs 任务状态。
- 直接调用 WMS 或调度平台数据库。

## 3. ROS2 Action 选型

最终采用两个 Action：

```text
LoadMaterials.action
UnloadMaterials.action
```

原因：

- 与 Nav2 `NavigateToPose` 的调用模式一致。
- 支持 goal、feedback、result、cancel。
- 上货和下货动作语义清晰，便于 ROS2 团队分别接不同硬件。
- Sidecar 可以统一封装为一个 HTTP `/api/v1/material-actions`，平台侧不用感知 ROS2 内部分两个 Action。

### 5.2 MaterialActual.msg


`status` 推荐值：

- `SUCCEEDED`
- `PARTIAL`
- `FAILED`
- `MISSING`
- `EXTRA`

## 8. 状态语义

Action result 的 `status` 只允许以下值：

- `SUCCEEDED`：全部完成。
- `PARTIAL`：部分完成，必须返回实际完成清单。
- `FAILED`：失败，必须返回 `error_code/message`。
- `CANCELLED`：被取消。
- `TIMEOUT`：车辆侧内部超时。

Feedback 的 `phase` 推荐值：

- `ACCEPTED`
- `CHECKING`
- `MOVING_ACTUATOR`
- `PICKING`
- `PLACING`
- `VERIFYING`
- `COMPLETING`

## 9. Action Server 行为要求

### 9.1 接收 goal

收到 goal 后必须校验：

- `job_id` 不为空。
- `vehicle_name` 与当前车辆匹配。
- `location_id` 或当前点位满足执行条件。
- `materials` 不为空。
- 本地处于可执行状态。

校验失败时直接返回：

```text
success=false
status=FAILED
error_code=VALIDATION_FAILED
message=明确失败原因
```

### 9.2 执行动作

执行时应持续发送 feedback：

- 当前阶段。
- 进度。
- 简短消息。

执行过程不要阻塞 ROS2 executor；硬件执行可放到独立线程、协程或 callback group。

### 9.3 返回结果

必须返回实际清单：

- 上货返回 `actual_loaded` 和 `current_load`。
- 卸货返回 `actual_unloaded` 和 `current_load`。
- 部分成功必须准确返回已完成清单。

本地平台只按实际清单更新库存，不按期望清单猜测。

### 9.4 取消

收到 cancel 时：

- 如果硬件动作尚未开始，直接取消。
- 如果硬件动作已开始但可安全停止，停止后返回 `CANCELLED`。
- 如果硬件动作不可安全停止，应返回 `FAILED` 或继续完成后返回实际结果，并在 message 中说明。

## 11. 可选载具状态 Topic

可选发布：

```text
/{namespace}/load_state
```

建议 JSON：

```json
{
  "vehicle_name": "AGV-01",
  "state": "LOADING",
  "current_load": [
    {
      "material_code": "MAT-001",
      "quantity": 1,
      "unit": "箱",
      "container_code": "C-001"
    }
  ],
  "timestamp": 1780050000000
}
```

状态值：

- `EMPTY`
- `LOADING`
- `LOADED`
- `UNLOADING`
- `UNKNOWN`

注意：该 topic 只做诊断和展示辅助，不作为库存最终更新依据。

## 12. 与 Sidecar 的对接约定

Sidecar 会按车辆 namespace 调用：

```text
/{namespace}/load_materials
/{namespace}/unload_materials
```

ROS2 端需要保证：

- Action server 启动后可被 Sidecar discovery 到。
- namespace 与车辆同步配置一致。
- Action result 中 `job_id` 必须原样返回。
- 不要主动回调 openTCS 或 WMS。
- 不要自行扣减平台库存。
